AWS Neuron SDK Release Notes - v2.31.1
=======================================

**Release Date**: August 12, 2026   

Release **2.31.1** of the AWS Neuron SDK includes bug fixes applied to the AWS Neuron SDK v2.31.0. See :doc:`the Neuron SDK v2.29.0 release notes </release-notes/2.31.0>` for the full set of changes that shipped with the 2.31.0 release.

Bug Fixes
----------

**Package updates to support this patch**: ``aws-neuron-tools-*`` → ``2.31.15``

Neuron Developer Tools
~~~~~~~~~~~~~~~~~~~~~~

* Updated the ``aws-neuron-tools-*`` package from version ``2.31.13`` to ``2.31.15`` for both RPM and Debian distributions.

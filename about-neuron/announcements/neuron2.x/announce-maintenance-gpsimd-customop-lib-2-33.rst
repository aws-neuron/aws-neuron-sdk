aws-neuronx-gpsimd-customop-lib is now in maintenance mode starting with Neuron 2.33.0
======================================================================================

Starting with :ref:`Neuron Release 2.33.0 <neuron-2-33-0-whatsnew>`, the
``aws-neuronx-gpsimd-customop-lib`` GpSIMD custom-operator library is in maintenance mode,
as :ref:`previously announced <announce-maintenance-gpsimd-customop-lib>` with Neuron
2.32.0. Support for the library is ending: it now receives critical security and bug fixes
only, and no new features are planned.

To implement custom operators, use the Neuron Kernel Interface (NKI). For NKI guidance,
see :doc:`/nki/index`.

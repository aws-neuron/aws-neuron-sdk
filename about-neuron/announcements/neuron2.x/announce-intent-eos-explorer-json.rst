Announcing end of support for the Neuron Explorer JSON output format starting with the next Neuron release
=============================================================================================================

:ref:`Neuron Release 2.33.0 <neuron-2-33-0-whatsnew>` is the last release to support the
Neuron Explorer full-profile JSON output (``--output-format json``). Migrate to the Parquet
output, which gives you a more structured and more performant way to analyze full profiles
programmatically.

For details, see :doc:`/tools/neuron-explorer/how-to-analyze-profile-output` and
:doc:`/tools/neuron-explorer/profile-schema-reference`, and the export guidance in
:doc:`/tools/neuron-explorer/get-started`.

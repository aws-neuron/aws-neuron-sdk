aws-neuronx-gpsimd-customop-lib enters maintenance mode starting with Neuron 2.33.0
----------------------------------------------------------------------------------------------

Neuron 2.32.0 is the last release with active development of the ``aws-neuronx-gpsimd-customop-lib`` GpSIMD custom-operator library. Starting with Neuron 2.33.0, the library will be in maintenance mode and will receive critical security and bug fixes only; no new features are planned.

To implement new custom operators, use the Neuron Kernel Interface (NKI). For NKI guidance, see :doc:`/nki/index`.
